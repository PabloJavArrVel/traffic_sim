# Traffic Sim — Simulación de Robotaxis Autónomos

Proyecto para la materia **Modelación de sistemas multiagentes con gráficas computacionales (Gpo 570)**.

A city of autonomous taxis, ambient traffic and pedestrians, built in Unity. Every car, taxi, pedestrian and the
taxi dispatcher is an agent that perceives, deliberates and acts each simulation step.

## How to run
1. Install **Unity 6000.3.25f1** (Unity Hub → Installs).
2. Open this folder as a Unity project.
3. Open `Assets/Scenes/City.unity` and press **Play**.
